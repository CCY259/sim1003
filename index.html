Tutorial 5 Exercise 9.6 Q48

From the discussion after the class in Group 8, an idea to express the series is $$\sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{(2n-1)^2} + \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{(2n)^2}.$$ Then we justify that both series converge absolutely and so the original series $\sum_{n=1}^{\infty}a_n$ converge absolutely as well.

The argument seems to have some flaws. The step $$\sum_{n=1}^{\infty}a_n = \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{(2n-1)^2} + \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{(2n)^2}$$ only valid after we have shown $\sum_{n=1}^{\infty}a_n$ is absolutely convergent, since we are considering rearrangement of series. Note that a series that converges but not absolutely (converges conditionally) is less robust. A rearrangement might give a series that converges to a different value, or even diverges.

Tutorial 5 Exercise 9.4 Q30

In Group 3, I proposed a way to find a candidate for the Direct Comparison Test, where I suggest the inequality $\ln n\leq n^{1/5}$. The candidate is just $\frac{1}{n^{3/2 - 2/5}} = \frac{1}{n^{11/10}}$ (see the note in Group 3 Week 8). However, I realized that it is difficult to find an exact number $N$ such that $\ln n \leq n^{1/5}$ for all $n \geq N$. There are two ways to fix this issue.

  • Use the Limit Comparison Test for the case where the limit is $0$. We can compare $\frac{(\ln n)^2}{n^{3/2}}$ with $\frac{1}{n^{11/10}}$. The limit can be found by L'Hôpital's rule.
  • Instead of finding an exact value for $N$, we can simply prove the existence of such $N$. By L'Hôpital's rule, $\lim_{n\rightarrow \infty} \frac{\ln n}{n^{1/5}} = 0$. By the definition of a limit of a sequence, there exists some integer $N > 0$ such that $\ln n < n^{1/5}$ for all $n \geq N$.

Tutorial 9 Exercise 11.4 Q40

There is a way to check the direction of the vectors: Just compute $\overrightarrow{AB}$ and $\overrightarrow{CD}$ to determine whether this pair is adjacent edges or diagonals. After that, you can draw a diagram to help you finding suitable vectors to find the area.

The above way seems to be redundant, as we can just consider any two vectors starting from $A$ (from $\overrightarrow{AB}$, $\overrightarrow{AC}$, and $\overrightarrow{AD}$). We can explain this issue using the properties of cross product. Let $\vec{u}$ and $\vec{v}$ be the adjacent edges from $A$. Then $\vec{u} + \vec{v}$ represents the diagonal. If we accidentally choose an edge and the diagonal to compute the area, we get $$|\vec{u} \times (\vec{u} + \vec{v})| = |(\vec{u} \times \vec{u}) + (\vec{u} \times \vec{v})| = |\vec{u} \times \vec{v}|$$ which get back the same area.

We can also explain it using geometrical perspective. See Remark on Tutorial 9 Exercise 11.4 Q40.
